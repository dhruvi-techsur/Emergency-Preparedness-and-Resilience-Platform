<objective>
Build the layout and navigation component layer: `Card` (the single grouped-content container used by every subsequent screen), `PageHeader` (enforces the one-`h1`-per-page rule structurally), `Breadcrumbs`, `SideNav` (the app shell's primary navigation, role-scoped), and `Avatar`. These are the structural components the app shell (01-10) and every admin console screen (01-11/12/13) compose.

Purpose: Without `SideNav`/`PageHeader`/`Card`, no real screen in this phase can be built — they are the load-bearing layout primitives named explicitly in F0's screens (S0.1 App Shell) and every subsequent FRD screen spec ("`PageHeader` with...", "`Table` inside a `Card padded={false}`...").
Output: 5 components added to `window.EPMP`, building on 01-02's foundation.
</objective>
