Close UAT gap ref 4 ("WCAG contrast compliance across all three themes"). Re-derived per the planning context's gap-confidence instruction: the UAT's own self-check for test 4 says this is a MISSING VERIFICATION TOOL, not a confirmed defect — "tokens.css defines complete light/dark/contrast palettes and 23 unit tests confirm correct per-theme CSS custom-property cascading, but no rendered-pixel contrast-ratio tool is installed in this project to independently verify WCAG AA compliance." Manual sRGB luminance-ratio computation against `tokens.json`'s actual hex values (done as part of this plan's own discovery, not taken on faith) confirms the hypothesis partially: every pairing used by a rendered, reachable component meets WCAG AA (4.5:1 body text) in dark and contrast themes, and meets it in light theme EXCEPT one real defect — light theme's `--ink-disabled` (`#8794a0`) against `--bg` (`#ffffff`) measures 3.10:1, below the 4.5:1 floor. Purpose: Install the missing automated contrast-ratio tool (so every future phase's gates re-verify this automatically, per the platform's own instruction to prefer permanent regression assets over one-off checks) AND fix the one real defect it (and this plan's own pre-verification) found, rather than only adding the tool and leaving a known-broken token in place.
Output: `@axe-core/playwright`-based Playwright spec scanning the signed-in AppShell (and the two DatePicker-bearing admin screens) for `color-contrast` violations in all three themes; `tokens.json`/`tokens.css`'s light-theme `--ink-disabled` corrected to a WCAG-AA-passing value.
</objective>

function hexToRgb(hex){hex=hex.replace('#','');const n=parseInt(hex,16);return [(n>>16)&255,(n>>8)&255,n&255];}
function lum([r,g,b]){const f=c=>{c=c/255;return c<=0.03928?c/12.92:Math.pow((c+0.055)/1.055,2.4);};const [R,G,B]=[r,g,b].map(f);return 0.2126*R+0.7152*G+0.0722*B;}
function contrast(a,b){const L1=lum(hexToRgb(a)),L2=lum(hexToRgb(b));const hi=Math.max(L1,L2),lo=Math.min(L1,L2);return (hi+0.05)/(lo+0.05);}
const fs=require('fs');
const tokens=JSON.parse(fs.readFileSync('frontend/design-system/tokens/tokens.json','utf-8'));
