```sql
SELECT hfc.feed_name,
       COUNT(hl.id) AS count,
       MAX(hfe.issued_at) AS as_of,
       bool_and(hl.verified) AS all_verified
FROM hazard_feed_config hfc
JOIN hazard_feed_events hfe ON hfe.feed_id = hfc.id
JOIN hazard_layers hl ON hl.hazard_feed_event_id = hfe.id
WHERE hfc.active = true
GROUP BY hfc.feed_name, hfc.id
```
A feed with zero ingested events yet (`bool_and` over an empty set is `NULL`, same as `COUNT` being `0`) is simply omitted from the layers array — no fake empty layer, matching the existing 'incidents'/'resource-requests' entries' convention of only appearing when they have something to show. {
  id: `hazard-${feed_name.toLowerCase()}`,
